# Brand assets (placeholders)

The official GoTrip logo and promotional banner were not supplied with the build,
so these SVG files are placeholders in the brand palette:

| File | Used for | Replace with |
| --- | --- | --- |
| `logo.svg` | Header/footer on dark backgrounds | Official horizontal logo (SVG or PNG, transparent) |
| `logo-mark.svg`, `favicon.svg` | Favicon, admin sidebar, compact header | Square logo mark |
| `hero-banner.svg` | Home page hero background | Promotional banner or a professional car photo (min. 1920x1080, JPG/WebP) |
| `og-image.svg` | Social link previews | 1200x630 PNG/JPG banner (most social sites do not render SVG previews) |

Keep the same file names (or update the paths in `src/lib/brand.ts`).
